# ValueStart

ValueStart is a three-page business valuation prototype for an MBA Investment Banking & Capital Markets project.

## Run locally
Open `index.html` in any modern browser.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example, `ValueStart`).
2. Upload all files from this folder to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Current features
- Company and financial inputs
- Five-year DCF forecast
- Revenue and EBITDA multiple valuation
- Forecast charts and tables
- WACC / terminal growth sensitivity analysis
- Automated valuation diagnostics
- Demo premium-payment interface
- Printable valuation report

## Important
The payment section is a prototype and does not process real payments. Do not place payment gateway secret keys or AI API keys in frontend JavaScript. Use a secure backend for production integrations.
